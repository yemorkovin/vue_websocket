# Парсер расписаний Airtable
## Описание
Проект автоматически собирает данные из Airtable с использованием Seleniu, сохраняя в формате JSON и предоставляет API через DJango. Используется Docker-окружение.

## Установка и запуск

### Требования
- Docker 20.10+
- Docker Compose 2.0+

### Запуск
```bash
docker-compose build
docke-compose up
